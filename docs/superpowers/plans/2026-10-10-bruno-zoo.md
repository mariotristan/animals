# Bruno's Zoo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish "Bruno's Zoo", a static, bilingual (EN/ES) browser game that teaches kids aged 7–10 the names and sounds of 36 animals through Explore and Quiz modes.

**Architecture:** One `index.html` loads ES modules directly (no build step). Pure, unit-tested modules (`quiz.js`, `progress.js`, `i18n.js`, data files) hold all logic; thin screen modules render DOM into one root element through a shared `ctx` object owned by `main.js`. Audio (recorded clips, Web Audio chimes, speech synthesis) is isolated in `audio.js` and fails safe.

**Tech Stack:** HTML, CSS, JavaScript ES modules; `node --test` (Node 23, no dependencies) for tests; `ffmpeg` (dev-only, Homebrew) to prepare sound clips; GitHub Pages for hosting.

**Spec:** `docs/superpowers/specs/2026-10-10-bruno-zoo-design.md`

## Global Constraints

- Plain HTML/CSS/JS ES modules, no build step, no runtime dependencies, no framework.
- `package.json` exists only for `npm test` → `node --test`; no dependencies.
- All file paths relative (game must work under `/animals/`).
- No network calls beyond the game's own files: no CDNs, web fonts, analytics, or trackers.
- 6 zones × 6 animals = 36 animals; zone order and unlock thresholds: Savanna 0, Jungle 2, Ocean 4, Polar 6, Farm 8, Forest 10.
- Stars per attempt from first-try-correct count out of 6: 6 → 3, 4–5 → 2, 0–3 → 1. Zone keeps best (0–3). Total = sum (max 18).
- Sticker earned permanently when an animal's question is answered correctly on the first try.
- Quiz unlocks once all 6 animals in the zone were visited at least once (saved).
- Wrong answer: Bruno encourages, the wrong option is dimmed, player retries. Nobody fails.
- Every UI string and Bruno line exists in both `en` and `es`, in `js/data/strings.js`.
- Touch targets ≥ 64 px; animal emoji ≈ 96 px+; works from ~360 px wide to desktop; real `<button>`s with `aria-label`s in the current language.
- Sounds: PD/CC0 preferred, then CC BY (CC BY-SA acceptable with attribution); never NC, ND, or unlicensed. Mono MP3 ~64 kbps, ~2–5 s, under 60 KB each, credited in `CREDITS.md` and the in-game About.
- Commits authored as `mariotristan <mariotristan@gmail.com>`. Publish to the existing repo `mariotristan/animals` with the `mariotristan` gh account (active account is a work account — switch first).

## Review Focus

1. **Double-tapping the correct answer** (kids tap fast) must record the answer once and advance once — pinned in Task 3 (`answer()` ignores input while awaiting the next question).
2. **Sounds turned off in Settings** must not produce unplayable "Who makes this sound?" questions — pinned in Task 3 (`buildQuiz(..., { allowSound: false })`).
3. **Saved data that is partly valid** (e.g. `bestStars.savanna = 99`, `stickers.lion = "yes"`, missing `settings` fields) must be cleaned or rejected, never crash or award 99 stars — pinned in Task 4 (`load` sanitizes).
4. **Storage that throws on write** (Safari private mode, quota full) must not crash the game — pinned in Task 4 (`save` returns `false`).
5. **Replaying a zone** must only announce stickers that are actually new, and keep the best star score — pinned in Task 4 (`newStickerIds`, `recordQuizResult`).

Also guarded in code (manually verified in Task 7): leaving a quiz mid-way via Back must not let a pending "next question" timer re-render a dead screen or save a partial result.

import { test } from "node:test";
import assert from "node:assert/strict";
import { ZONES, ANIMALS, animalsInZone, getAnimal } from "../js/data/animals.js";

const QUIET = ["giraffe", "shark", "octopus", "sea-turtle"];
const isText = (v) => typeof v === "string" && v.trim().length > 0;

test("zones are in unlock order with the spec thresholds", () => {
  assert.deepEqual(
    ZONES.map((z) => [z.id, z.threshold]),
    [["savanna", 0], ["jungle", 2], ["ocean", 4], ["polar", 6], ["farm", 8], ["forest", 10]],
  );
});

test("every zone has an emoji, colors, and a name in both languages", () => {
  for (const z of ZONES) {
    assert.ok(isText(z.emoji), z.id);
    for (const key of ["color", "sky", "ground"]) assert.match(z[key], /^#[0-9a-f]{6}$/i, `${z.id}.${key}`);
    assert.ok(isText(z.name.en) && isText(z.name.es), z.id);
  }
});

test("36 animals, 6 per zone, unique ids", () => {
  assert.equal(ANIMALS.length, 36);
  assert.equal(new Set(ANIMALS.map((a) => a.id)).size, 36);
  for (const z of ZONES) assert.equal(animalsInZone(z.id).length, 6, z.id);
  for (const a of ANIMALS) assert.ok(ZONES.some((z) => z.id === a.zone), `${a.id} zone`);
});

test("every animal has an emoji and en/es name, fact, and myth", () => {
  for (const a of ANIMALS) {
    assert.ok(isText(a.emoji), a.id);
    for (const field of ["name", "fact", "myth"]) {
      assert.ok(isText(a[field]?.en), `${a.id}.${field}.en`);
      assert.ok(isText(a[field]?.es), `${a.id}.${field}.es`);
    }
    assert.notEqual(a.fact.en, a.myth.en, `${a.id} fact vs myth`);
  }
});

test("quiet animals have no sound; all others use sounds/<id>.mp3", () => {
  for (const a of ANIMALS) {
    if (QUIET.includes(a.id)) assert.equal(a.sound, null, a.id);
    else assert.equal(a.sound, `sounds/${a.id}.mp3`, a.id);
  }
});

test("getAnimal finds by id", () => {
  assert.equal(getAnimal("lion").emoji, "🦁");
  assert.equal(getAnimal("nope"), undefined);
});

import { STRINGS } from "./data/strings.js";

const LANGS = ["en", "es"];
let current = "en";

export function setLang(lang) {
  if (LANGS.includes(lang)) current = lang;
}

export function getLang() {
  return current;
}

export function t(key, vars = {}) {
  const entry = STRINGS[key];
  if (!entry) return key;
  const text = entry[current] ?? entry.en;
  return text.replace(/\{(\w+)\}/g, (match, name) => (name in vars ? String(vars[name]) : match));
}

export function localized(field) {
  return field?.[current] ?? field?.en ?? "";
}

// Deterministic RNG (mulberry32) for repeatable tests.
export function seededRng(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

// Pure quiz logic: no DOM, no storage. Pass `rng` for deterministic tests.

export function shuffle(list, rng) {
  const a = list.slice();
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}

// Wrong choices: same zone first, other zones only if the zone runs out.
function pickDistractors(animal, animals, count, rng) {
  const sameZone = shuffle(animals.filter((a) => a.zone === animal.zone && a.id !== animal.id), rng);
  const otherZones = shuffle(animals.filter((a) => a.zone !== animal.zone), rng);
  return [...sameZone, ...otherZones].slice(0, count).map((a) => a.id);
}

function buildQuestion(animal, animals, rng, allowSound) {
  const types = allowSound && animal.sound ? ["sound", "name", "truefalse"] : ["name", "truefalse"];
  const type = types[Math.floor(rng() * types.length)];
  if (type === "truefalse") {
    const answer = rng() < 0.5;
    return { type, animalId: animal.id, statement: answer ? "fact" : "myth", choices: [true, false], answer };
  }
  const choices = shuffle([animal.id, ...pickDistractors(animal, animals, 2, rng)], rng);
  return { type, animalId: animal.id, choices, answer: animal.id };
}

export function buildQuiz(zoneId, animals, rng = Math.random, { allowSound = true } = {}) {
  const zoneAnimals = shuffle(animals.filter((a) => a.zone === zoneId), rng);
  return zoneAnimals.map((animal) => buildQuestion(animal, animals, rng, allowSound));
}

export function starsFor(correctFirstTry) {
  if (correctFirstTry >= 6) return 3;
  if (correctFirstTry >= 4) return 2;
  return 1;
}

export function scoreAttempt(results) {
  const firstTry = results.filter((r) => r.firstTry);
  return {
    correct: firstTry.length,
    stars: starsFor(firstTry.length),
    stickerIds: firstTry.map((r) => r.animalId),
  };
}

// Session reducer: tracks the attempt so the screen stays a thin view.
export function createSession(questions) {
  return { questions, index: 0, wrong: [], awaitingNext: false, results: [] };
}

export function currentQuestion(session) {
  return session.questions[session.index] ?? null;
}

export function answer(session, choice) {
  const q = currentQuestion(session);
  if (!q || session.awaitingNext || !q.choices.includes(choice) || session.wrong.includes(choice)) {
    return { session, outcome: "ignored" };
  }
  if (choice === q.answer) {
    const result = { animalId: q.animalId, firstTry: session.wrong.length === 0 };
    return { outcome: "correct", session: { ...session, awaitingNext: true, results: [...session.results, result] } };
  }
  return { outcome: "wrong", session: { ...session, wrong: [...session.wrong, choice] } };
}

export function advance(session) {
  if (!session.awaitingNext) return session;
  return { ...session, index: session.index + 1, wrong: [], awaitingNext: false };
}

export function isFinished(session) {
  return session.index >= session.questions.length;
}

// Pure progress state. Every function returns a new state; storage is injected.

export const VERSION = 1;
export const STORAGE_KEY = "bruno-zoo-progress";
const LANGS = ["en", "es"];

export function freshState() {
  return {
    version: VERSION,
    lang: "en",
    settings: { sfx: true, voice: true },
    visited: {},
    bestStars: {},
    stickers: {},
  };
}

export function markVisited(state, animalId) {
  if (state.visited[animalId]) return state;
  return { ...state, visited: { ...state.visited, [animalId]: true } };
}

export function recordQuizResult(state, zoneId, { stars, stickerIds }) {
  const stickers = { ...state.stickers };
  for (const id of stickerIds) stickers[id] = true;
  const best = Math.max(state.bestStars[zoneId] ?? 0, stars);
  return { ...state, bestStars: { ...state.bestStars, [zoneId]: best }, stickers };
}

export function newStickerIds(state, stickerIds) {
  return stickerIds.filter((id) => !state.stickers[id]);
}

export function totalStars(state) {
  return Object.values(state.bestStars).reduce((sum, n) => sum + n, 0);
}

export function isZoneUnlocked(state, zone) {
  return totalStars(state) >= zone.threshold;
}

export function newlyUnlockedZones(before, after, zones) {
  return zones.filter((z) => !isZoneUnlocked(before, z) && isZoneUnlocked(after, z)).map((z) => z.id);
}

export function visitedCount(state, zoneId, animals) {
  return animals.filter((a) => a.zone === zoneId && state.visited[a.id]).length;
}

export function isQuizUnlocked(state, zoneId, animals) {
  const total = animals.filter((a) => a.zone === zoneId).length;
  return total > 0 && visitedCount(state, zoneId, animals) === total;
}

export function setLanguage(state, lang) {
  if (!LANGS.includes(lang)) return state;
  return { ...state, lang };
}

export function setSetting(state, key, value) {
  return { ...state, settings: { ...state.settings, [key]: Boolean(value) } };
}

export function resetProgress(state) {
  return { ...freshState(), lang: state.lang, settings: { ...state.settings } };
}

const isObject = (v) => v !== null && typeof v === "object" && !Array.isArray(v);

function trueKeys(obj) {
  const out = {};
  for (const [key, value] of Object.entries(obj)) if (value === true) out[key] = true;
  return out;
}

// Returns a clean state, or null if the shape or version is wrong.
export function validate(raw) {
  if (!isObject(raw) || raw.version !== VERSION || !LANGS.includes(raw.lang)) return null;
  if (![raw.settings, raw.visited, raw.bestStars, raw.stickers].every(isObject)) return null;
  const bestStars = {};
  for (const [zoneId, n] of Object.entries(raw.bestStars)) {
    if (Number.isInteger(n) && n >= 0 && n <= 3) bestStars[zoneId] = n;
  }
  return {
    version: VERSION,
    lang: raw.lang,
    settings: { sfx: raw.settings.sfx !== false, voice: raw.settings.voice !== false },
    visited: trueKeys(raw.visited),
    bestStars,
    stickers: trueKeys(raw.stickers),
  };
}

export function load(storage) {
  try {
    const text = storage.getItem(STORAGE_KEY);
    if (!text) return freshState();
    return validate(JSON.parse(text)) ?? freshState();
  } catch (err) {
    console.warn("Could not load progress; starting fresh.", err);
    return freshState();
  }
}

export function save(storage, state) {
  try {
    storage.setItem(STORAGE_KEY, JSON.stringify(state));
    return true;
  } catch (err) {
    console.warn("Could not save progress.", err);
    return false;
  }
}

export function memoryStorage() {
  const map = new Map();
  return {
    getItem: (key) => (map.has(key) ? map.get(key) : null),
    setItem: (key, value) => void map.set(key, String(value)),
    removeItem: (key) => void map.delete(key),
  };
}

// localStorage if it works (it can throw in private mode), else in-memory.
export function browserStorage() {
  try {
    const storage = globalThis.localStorage;
    const probe = "__bruno_zoo_probe__";
    storage.setItem(probe, "1");
    storage.removeItem(probe);
    return storage;
  } catch {
    return memoryStorage();
  }
}

// All audio is fail-safe: errors are logged and the game keeps going.

let settings = { sfx: true, voice: true };
let currentClip = null;
let audioContext = null;

export function configureAudio(next) {
  settings = { ...settings, ...next };
  if (!settings.sfx) stopSound();
  if (!settings.voice) cancelSpeech();
}

export function pickVoice(voices, lang) {
  const tagOf = (v) => (v.lang ?? "").toLowerCase().replace("_", "-");
  return (
    voices.find((v) => tagOf(v).startsWith(`${lang}-`)) ??
    voices.find((v) => tagOf(v) === lang) ??
    null
  );
}

export function speakable(text) {
  return text
    .replace(/\p{Extended_Pictographic}|‍|️/gu, "")
    .replace(/\s+/g, " ")
    .trim();
}

function stopSound() {
  if (!currentClip) return;
  try {
    currentClip.pause();
  } catch {
    // ignore
  }
  currentClip = null;
}

function cancelSpeech() {
  try {
    globalThis.speechSynthesis?.cancel();
  } catch {
    // ignore
  }
}

export function stopAll() {
  stopSound();
  cancelSpeech();
}

export function playSound(path, { maxMs = 6000 } = {}) {
  if (!settings.sfx || !path) return Promise.resolve(false);
  stopSound();
  return new Promise((resolve) => {
    let done = false;
    const finish = (ok) => {
      if (done) return;
      done = true;
      clearTimeout(timer);
      resolve(ok);
    };
    const timer = setTimeout(() => finish(true), maxMs);
    try {
      const clip = new Audio(path);
      currentClip = clip;
      clip.addEventListener("ended", () => finish(true));
      clip.addEventListener("pause", () => finish(true));
      clip.addEventListener("error", () => {
        console.warn("Sound failed to load:", path);
        finish(false);
      });
      clip.play()?.catch((err) => {
        console.warn("Sound could not play:", path, err);
        finish(false);
      });
    } catch (err) {
      console.warn("Sound unavailable:", path, err);
      finish(false);
    }
  });
}

export function speak(text, lang, { maxMs = 10000 } = {}) {
  const synth = globalThis.speechSynthesis;
  const words = speakable(text ?? "");
  if (!settings.voice || !synth || typeof SpeechSynthesisUtterance === "undefined" || !words) {
    return Promise.resolve();
  }
  return new Promise((resolve) => {
    let done = false;
    const finish = () => {
      if (done) return;
      done = true;
      clearTimeout(timer);
      resolve();
    };
    const timer = setTimeout(finish, maxMs);
    try {
      synth.cancel();
      const utterance = new SpeechSynthesisUtterance(words);
      utterance.lang = lang === "es" ? "es-ES" : "en-US";
      const voice = pickVoice(synth.getVoices(), lang);
      if (voice) utterance.voice = voice;
      utterance.rate = 0.9;
      utterance.onend = finish;
      utterance.onerror = finish;
      synth.speak(utterance);
    } catch (err) {
      console.warn("Speech failed:", err);
      finish();
    }
  });
}

export function chime(kind) {
  if (!settings.sfx) return;
  try {
    const AudioCtx = globalThis.AudioContext ?? globalThis.webkitAudioContext;
    if (!AudioCtx) return;
    audioContext ??= new AudioCtx();
    const notes = kind === "correct" ? [523.25, 659.25, 783.99] : [392, 330];
    notes.forEach((freq, i) => {
      const start = audioContext.currentTime + i * 0.12;
      const osc = audioContext.createOscillator();
      const gain = audioContext.createGain();
      osc.type = "sine";
      osc.frequency.value = freq;
      gain.gain.setValueAtTime(0.0001, start);
      gain.gain.exponentialRampToValueAtTime(0.25, start + 0.02);
      gain.gain.exponentialRampToValueAtTime(0.0001, start + 0.25);
      osc.connect(gain).connect(audioContext.destination);
      osc.start(start);
      osc.stop(start + 0.3);
    });
  } catch (err) {
    console.warn("Chime failed:", err);
  }
}

// Small DOM helpers shared by screens.
import { setLanguage } from "./progress.js";

export function h(tag, attrs = {}, ...children) {
  const el = document.createElement(tag);
  for (const [key, value] of Object.entries(attrs)) {
    if (value == null || value === false) continue;
    if (key === "class") el.className = value;
    else if (key.startsWith("on") && typeof value === "function") el.addEventListener(key.slice(2), value);
    else el.setAttribute(key, value === true ? "" : value);
  }
  for (const child of children.flat(Infinity)) {
    if (child == null || child === false) continue;
    el.append(child instanceof Node ? child : String(child));
  }
  return el;
}

export function screen(...children) {
  return h("section", { class: "screen" }, ...children);
}

export function starsText(n, max = 3) {
  return "⭐".repeat(n) + "☆".repeat(Math.max(0, max - n));
}

// Bruno with a speech bubble. Tap Bruno to hear the line again.
export function bruno(ctx, text, { speakNow = true } = {}) {
  const bubble = h("p", { class: "bubble", "aria-live": "polite" }, text);
  const face = h(
    "button",
    { class: "bruno-face", "aria-label": ctx.t("brunoRepeat"), onclick: () => ctx.audio.speak(bubble.textContent) },
    "🧑‍🌾",
  );
  const el = h("div", { class: "bruno" }, face, bubble);
  el.say = (line) => {
    bubble.textContent = line;
    return ctx.audio.speak(line);
  };
  if (speakNow) ctx.audio.speak(text);
  return el;
}

export function backButton(ctx, to, params = {}) {
  return h("button", { "aria-label": ctx.t("back"), onclick: () => ctx.navigate(to, params) }, "⬅️");

import { t, localized, setLang, getLang } from "./i18n.js";

const SCREENS = { welcome, map, zone, quiz, results, stickers, settings };

export function start() {
  const root = document.getElementById("app");
  const storage = browserStorage();
  let state = load(storage);
  let current = { name: "welcome", params: {} };

  const applyState = () => {
    setLang(state.lang);
    configureAudio(state.settings);
    document.documentElement.lang = state.lang;
    document.title = t("appTitle");
  };

  const renderCurrent = () => {
    stopAll();
    const scenery = ZONES.find((z) => z.id === current.params.zoneId);
    document.body.style.setProperty("--sky", scenery?.sky ?? "");
    document.body.style.setProperty("--ground", scenery?.ground ?? "");
    root.replaceChildren();
    (SCREENS[current.name] ?? map).render(root, ctx);
    root.querySelector("h1")?.focus();
  };

  const ctx = {
    get state() { return state; },
    get params() { return current.params; },
    get lang() { return getLang(); },
    data: { ZONES, ANIMALS },
    t,
    localized,
    audio: {
      playSound: (path) => playSound(path),
      speak: (text) => speak(text, getLang()),
      chime,
      stop: stopAll,
    },
    update(fn) {
      state = fn(state);
      save(storage, state);
      applyState();
    },
    navigate(name, params = {}) {
      current = { name, params };
      renderCurrent();
    },
    rerender: () => renderCurrent(),
  };

  applyState();
  renderCurrent();
}

import { h, screen, bruno, backButton } from "../ui.js";
import { buildQuiz, scoreAttempt, createSession, currentQuestion, answer, advance, isFinished } from "../quiz.js";
import { isQuizUnlocked, recordQuizResult, newStickerIds, newlyUnlockedZones } from "../progress.js";
import { getAnimal } from "../data/animals.js";

const NEXT_DELAY_MS = 1400;
const pick = (keys) => keys[Math.floor(Math.random() * keys.length)];

export function render(root, ctx) {
  const { zoneId } = ctx.params;
  const zone = ctx.data.ZONES.find((z) => z.id === zoneId);
  if (!zone || !isQuizUnlocked(ctx.state, zoneId, ctx.data.ANIMALS)) return ctx.navigate("map");

  let session = createSession(
    buildQuiz(zoneId, ctx.data.ANIMALS, Math.random, { allowSound: ctx.state.settings.sfx }),
  );
  const view = screen();
  root.append(view);

  const choiceButton = (q, choice) => {
    if (q.type === "truefalse") {
      return h("button", { class: "choice" },
        h("span", { class: "emoji", "aria-hidden": "true" }, choice ? "👍" : "👎"),
        ctx.t(choice ? "true" : "false"));
    }
    const animal = getAnimal(choice);
    const name = ctx.localized(animal.name);
    return h("button", { class: "choice", "aria-label": name },
      h("span", { class: "emoji", "aria-hidden": "true" }, animal.emoji),
      q.type === "sound" ? h("span", { "aria-hidden": "true" }, name) : null);
  };

  const finish = () => {
    const score = scoreAttempt(session.results);
    const before = ctx.state;
    const newStickers = newStickerIds(before, score.stickerIds);
    ctx.update((s) => recordQuizResult(s, zoneId, score));
    const unlocked = newlyUnlockedZones(before, ctx.state, ctx.data.ZONES);
    ctx.navigate("results", { zoneId, stars: score.stars, correct: score.correct, newStickers, unlocked });
  };

  const showQuestion = () => {
    const q = currentQuestion(session);
    const animal = getAnimal(q.animalId);
    const prompt =
      q.type === "sound" ? ctx.t("qSound")
      : q.type === "name" ? ctx.t("qName", { name: ctx.localized(animal.name) })
      : `${ctx.t("qTrueFalse")} ${ctx.localized(animal[q.statement])}`;
    const brunoEl = bruno(ctx, prompt, { speakNow: q.type !== "sound" });

    const visual =
      q.type === "sound"
        ? h("div", { class: "row" },
            h("button", { class: "replay", "aria-label": ctx.t("playSound"), onclick: () => ctx.audio.playSound(animal.sound) }, "🔊"))
        : q.type === "truefalse"
          ? h("div", { class: "question-visual", "aria-hidden": "true" }, animal.emoji)
          : null;

    const buttons = q.choices.map((choice) => {
      const btn = choiceButton(q, choice);
      btn.addEventListener("click", () => {
        const result = answer(session, choice);
        session = result.session;
        if (result.outcome === "wrong") {
          btn.disabled = true;
          ctx.audio.chime("wrong");
          brunoEl.say(ctx.t(q.type === "sound" ? "encourageSound" : pick(["encourage1", "encourage2"])));
        } else if (result.outcome === "correct") {
          btn.classList.add("correct");
          ctx.audio.chime("correct");
          brunoEl.say(ctx.t(pick(["cheer1", "cheer2", "cheer3"])));
          setTimeout(() => {
            if (!view.isConnected) return; // player left the quiz
            session = advance(session);
            if (isFinished(session)) finish();
            else showQuestion();
          }, NEXT_DELAY_MS);
        }
      });
      return btn;
    });

    view.replaceChildren(
      h("div", { class: "topbar" },
        backButton(ctx, "zone", { zoneId, quiet: true }),
        h("span", { class: "pill progress-text" },
          ctx.t("questionOf", { n: session.index + 1, total: session.questions.length }))),
      h("h1", { tabindex: "-1" }, `${zone.emoji} ${ctx.t("quiz")}`),
      brunoEl,
      visual,
      h("div", { class: "choices" }, buttons),
    );
    view.querySelector("h1").focus();

    if (q.type === "sound") {
      ctx.audio.speak(prompt).then(() => {
        if (view.isConnected && currentQuestion(session) === q) ctx.audio.playSound(animal.sound);
      });
    }
  };

  showQuestion();
}

import { test } from "node:test";
import assert from "node:assert/strict";
import { existsSync, statSync, readFileSync } from "node:fs";
import { ANIMALS } from "../js/data/animals.js";
import { CREDITS } from "../js/data/credits.js";

const ALLOWED = /^(Public domain|CC0( 1\.0)?|CC BY( \d\.\d)?|CC BY-SA( \d\.\d)?)$/;
const withSound = ANIMALS.filter((a) => a.sound);

test("every sound file exists and is under 60 KB", () => {
  for (const a of withSound) {
    assert.ok(existsSync(a.sound), `missing ${a.sound}`);
    assert.ok(statSync(a.sound).size < 60 * 1024, `${a.sound} too big`);
  }
});

test("every sound has exactly one complete credit with an allowed license", () => {
  for (const a of withSound) {
    const matches = CREDITS.filter((c) => c.file === a.sound);
    assert.equal(matches.length, 1, a.sound);
    const c = matches[0];
    assert.equal(c.animal, a.id);
    for (const key of ["title", "author", "source", "license", "licenseUrl"]) assert.ok(c[key]?.trim(), `${a.id}.${key}`);
    assert.match(c.license, ALLOWED, `${a.id} license`);
    assert.match(c.source, /^https:\/\//);
  }
  assert.equal(CREDITS.length, withSound.length, "no extra credits");
});

test("CREDITS.md is generated from credits.js", () => {
  const md = readFileSync("CREDITS.md", "utf8");
  for (const c of CREDITS) {
    assert.ok(md.includes(c.file), `CREDITS.md missing ${c.file}`);
    assert.ok(md.includes(c.source), `CREDITS.md missing ${c.source}`);

Rules: accept `LicenseShortName` of Public domain / CC0 / CC BY x / CC BY-SA x only. Prefer PD/CC0, then CC BY, then CC BY-SA. Strip HTML from `Artist` for the credit. Listen-check is not possible here, so prefer files whose title/description clearly name the species and call (e.g. "Lion roaring.ogg", "Cow mooing.ogg").
